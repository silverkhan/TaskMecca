# Telegram 알림 발신 컴퓨터 구분

Task Mecca를 여러 컴퓨터에 설치하고 같은 Telegram 봇과 채팅을 연결해도, 알림 본문에 **발신 컴퓨터 이름**과 **프로젝트명**을 함께 표시합니다.

예시:

```text
▶️ 작업 착수
💻 컴퓨터: 업무용-Mac
[TaskMecca] B-412 · 리스크 모델 개선
작업이 착수 상태로 전환되었습니다.
```

- 모든 일반 작업 알림(등록·착수·완료·승인·경고 등) 및 Telegram 연결 테스트 메시지에 적용합니다.
- 기본 컴퓨터명은 Task Mecca **Web 서버가 실행되는 컴퓨터의 운영체제 호스트명**입니다.
- 같은 이름을 가진 컴퓨터가 여러 대라면 서버 프로세스 환경변수 `TASK_MECCA_MACHINE_NAME`으로 각각 별칭을 지정할 수 있습니다(예: `업무용-Mac`, `집-Windows`). 변수는 해당 Task Mecca 프로세스의 실행 환경에 있어야 하며, 셸에만 임시 지정하면 시스템 서비스 재시작 후 유지되지 않을 수 있습니다.
- 별칭은 줄바꿈·제어 문자를 제거하고 최대 48자로 제한합니다. 프로젝트명·작업 ID·제목·이벤트 정합성은 그대로 유지합니다.
- 컴퓨터명은 Telegram 메시지에 포함되므로 수신 채팅 참가자에게 노출됩니다. 기밀 내부 호스트명이 노출되지 않도록 필요시 일반적인 별칭을 사용하세요.
- 컴퓨터명은 표시용 메타데이터이며 전송 중복 방지 원장의 키나 동일 기계의 보안 인증 ID로 사용하지 않습니다. 두 컴퓨터의 이름이 같으면 구분이 어려우므로 별칭을 다르게 설정하세요.
