## 자동 검증 근거

- [RC 빌드/게시 파이프라인](https://github.com/silverkhan/TaskMecca/actions/runs/37893286914): Go 전체 테스트·정적 검사·웹 UI 회귀·4종 아티팩트 빌드 및 RC 게시 성공. 초기 Unix CI smoke는 `head` 파이프의 SIGPIPE(141)로 중단되어 별도 교차 OS 검증으로 대체했다.
- [게시된 RC의 교차 OS 재검증](https://github.com/silverkhan/TaskMecca/actions/runs/37893805456): Linux, Windows, macOS 모두 성공. Stable 0.2.52 설치 → RC 실행 파일 교체 → 변경된 사용자 문서 백업을 포함한 `migrate` → 사용자 데이터 보존 → Web health 응답 확인.
- macOS GitHub Actions는 대화형 LaunchAgent 세션이 아니므로 Web 전경 실행으로 HTTP 기능을 확인했다. 실제 GUI 사용자의 백그라운드 서비스 업그레이드·롤백 검증을 대신하지 않는다.
- Python 레거시 제거 PR #179: Go 전용 CI 검증 후 dev 병합 완료.

## 릴리즈 운영 원칙

이 문서는 automated CI 통과와 **운영환경 검증 완료**를 구분한다. 위 체크리스트가 완료되지 않았다면 Stable`main` 병합 및 `release-stable` 갱신을 수행하지 않는다. 일반 사용자에게 RC 자동 업데이트를 노출하지 않는다.
