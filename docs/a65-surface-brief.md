# A-65 Smoke core surface brief

Task Mecca is a read-focused control center for multiple projects. Core order: attention, working tasks, projects, notification journal activity. Dedicated task screens preserve source requirements, execution evidence and connected lifecycle bars. Desktop and mobile have the same core data and controls.

The user selected Smoke: neutral light/dark surfaces, asymmetric thin reflections, soft depth and restrained blue. Original logo preserved. Concept seed 48a9eb3c is subordinate to this pinned direction. No new concept approval gate.

Native ES modules separate state, data, components and screens. Main home consumes a single server aggregate; cold loading uses a finite refresh path. Unknown data remains distinct from zero. Workflow uses the existing tested interval renderer and gestures in a native module, with no permanent render loop.

Review gate: real core, exact HEAD CI, isolated Preview, desktop/mobile Light/Dark evidence and performance comparison. Do not mark all A-65 acceptance criteria complete before user review.

Release notes/version/update prompts, help/manual, terminal, storage, and project Activity queries remain mapped residuals after core design review; existing server APIs and compatibility assets remain preserved.
