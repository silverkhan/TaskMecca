# A-65 플로팅 시안의 중립색·투명도 보완

사용자 원문: “Mecca의 배색이 적용되어 있는데 직전에 Dark, Light의 검정, 하양 기준의 배색과 투명도를 적용해보자”

기존 dev UI 보존 플로팅 시안의 표면 배색만 보완한다. Dark는 검정·중립 회색, Light는 흰색·중립 회색 기반의 앞서 논의한 반투명 소재로 표현한다. Mecca에서 유래한 보라·남색의 표면 틴트와 장식 테두리를 제거한다. 이전 재구현 UI의 DOM·기능·실시간 굴절·마우스 추적 엔진은 재도입하지 않는다.

직전 목록 가독성 보완의 연속 읽기 배경·사이드바 바깥 여백·상단 정렬·곡률은 유지한다. 배경이 은은하게 비치도록 표면 역할별 alpha를 정하되, 목록/본문 텍스트가 사진에 직접 노출되는 문제를 재발시키지 않는다. 이전 시안의 실제 neutral/alpha 토큰을 참고하고 값의 출처·선택 이유를 기록한다. 모든 표면에 같은 alpha를 무조건 적용하지 않는다.

선택·focus를 중립 경계로 명확히 구분한다. 완료·보류·경고·오류 등의 의미색 및 로고의 브랜드 의미는 보존한다. 일반 Mecca/Slate 등 기존 테마의 배색은 바꾸지 않고 floating 시안 범위에 한정한다. Dark/Light/System 및 PC/모바일에서 확인한다. 삼성 실기 성능·최종 디자인 수용은 검증 없이 주장하지 않는다.
