# 텔레그램 알림의 프로젝트·작업 표기

알림 접두어는 실제 프로젝트 경로의 마지막 폴더명을 사용한다. 프로젝트명이 `운영-A-31`이면 원문을 유지해 `[운영-A-31]`로 표시한다.

작업 표기는 canonical 작업 ID를 유지하고 제목 시작의 같은 독립 ID·구분자만 정리한다. `A-31 · A-31 작업제목`은 `A-31 · 작업제목`이 된다. 다른 ID, 더 긴 ID, 제목의 나머지 내용, 본문의 의미 있는 작업 참조와 재개조건은 보존한다. URL에 포함된 ID와 프로젝트명 안의 ID는 중복 제한 대상이 아니다.

수신처·활성화·알림 유형·전송 원장·재시도·중복 전송 방지 정책은 그대로다. 실제 메시지 소비자 검증은 임시 프로젝트와 mock Telegram에서 수행하며 운영 Telegram에 시험 메시지를 보내지 않는다. Python 패키지에는 별도 Telegram 전송 구현이 없고 실제 전송 경로는 Go의 `internal/notify`다.
