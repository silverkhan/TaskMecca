Task Mecca

여러 AI 에이전트의 작업을 연결하고, 세션이 바뀌어도 이어갑니다.

Task Mecca는 백로그 기반의 AI 에이전트 오케스트레이션 및 작업 관리 도구입니다. 사용자 요청의 역할 분담, 실행 이력, 세션 간 작업 인계와 진행 상황을 한곳에서 관리합니다.

GitHub 저장소 보기설치 및 빠른 시작English README

주요 기능

작업에 맞춘 역할 분담

Controller가 적합한 Worker에게 업무를 맡기고 작업 결과와 상태를 백로그로 관리합니다.

세션을 넘는 연속성

연결된 작업 이력과 인계 정보로 담당 에이전트나 실행 세션이 달라져도 문맥을 이어갑니다.

진행 상황과 알림

Web UI에서 작업 상태·실행 이력을 확인하고 Telegram 및 브라우저 알림을 활용할 수 있습니다.

Multi-agent task orchestration, without losing context

Task Mecca coordinates AI agent work through a persistent backlog. It supports worker assignment, cross-session handoffs, execution history, web-based progress monitoring, and notifications. Explore the English documentation.
